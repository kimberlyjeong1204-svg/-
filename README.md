# 쉼표.

몰입하는 일상에, 잠깐의 여유.

일이나 일상에 몰입하다 쉬는 것을 잊는 사람을 위한 iPhone 앱입니다.
React Native + Expo + TypeScript로 만듭니다.

## 하나의 코드로 두 가지

- **웹앱(PWA):** Vercel에 배포해 휴대폰 브라우저에서 바로 쓰고 홈 화면에 추가할 수 있습니다. 배포 방법은 [DEPLOY.md](DEPLOY.md)를 보세요.
- **iOS 앱:** 같은 코드로 App Store용 앱을 만듭니다(Expo / EAS Build).

## 지금 들어 있는 기능

- 홈: 숨 고르기, 멍때리기, 알림 설정으로 이동
- 숨 고르기: 들이쉬기 3초 / 내쉬기 5초 (느리게 4초 / 6초), 30초 / 1분 / 3분, 시작·일시정지·그만하기
- 멍때리기: 30초 / 1분 / 3분, 남은 시간 숨기기, 끝나면 조용히 홈으로
- 소리: 소리 없음 / 잔잔한 비 / 가벼운 비 / 내 음악과 함께 (기본 무음, 끝날 때 천천히 작아짐)
- 다른 앱(YouTube Music, Spotify, Apple Music 등)에서 듣던 음악을 끊지 않음
- 알림 설정: 휴식 알림(종류·간격·시간대·요일), 취침 알림(시간·요일) 선택과 저장, iOS 알림 개수 제한 안내
- 선택값은 모두 기기에만 저장 (서버 없음)
- 웹앱: 홈 화면에 추가, 오프라인 실행, 아이폰·안드로이드·PC 화면 크기 대응

실제 알림 보내기는 3단계(iOS 앱)에서 연결합니다. 웹앱은 서버 없이 예약 알림을 보낼 수 없어 설정만 저장합니다.

## Windows PC에서 iPhone으로 실행해 보기

1. PC에 [Node.js LTS](https://nodejs.org)와 [Git](https://git-scm.com)을 설치합니다.
2. iPhone에 App Store에서 **Expo Go** 앱을 설치합니다.
3. PC의 명령 프롬프트(또는 PowerShell)에서:

   ```bash
   git clone <이 저장소 주소>
   cd <저장소 폴더>
   git checkout claude/shuimpo-ios-app-h4iu78
   npm install
   npx expo start
   ```

4. 화면에 나온 QR 코드를 iPhone 카메라로 찍으면 Expo Go에서 앱이 열립니다.
   - PC와 iPhone이 같은 Wi-Fi에 있어야 합니다.
   - 연결이 안 되면 `npx expo start --tunnel`로 다시 실행합니다.

## 「내 음악과 함께」 동작 방식

- 쉼표.는 외부 음악을 직접 재생하거나 내려받지 않습니다. 사용자가 음악 앱에서 틀어 둔 음악을 그대로 둡니다.
- 「소리 없음」과 「내 음악과 함께」에서는 쉼표.가 오디오를 아예 켜지 않습니다.
- 빗소리를 쓸 때는 iOS의 `ambient` 오디오 방식(다른 앱 소리와 섞임, 무음 스위치를 따름)으로 재생해 다른 앱 음악을 멈추지 않습니다.
- 빗소리를 골랐더라도 다른 앱 음악이 재생 중이면 빗소리는 켜지 않습니다. 휴식 중에 음악이 멈추면 빗소리가 천천히 들어옵니다.
  - 이 감지는 `modules/other-audio`의 작은 iOS 모듈이 합니다. **Expo Go에는 이 모듈이 없어서 감지가 동작하지 않고**, 개발 빌드나 App Store 빌드에서 동작합니다.
- 음악 앱으로 전환하거나 제어 센터에서 곡을 넘겨도 타이머는 멈추지 않습니다. 돌아오면 실제 흐른 시간만큼 진행되어 있습니다.

## 실제 iPhone에서 음악과 함께 테스트하기

음악 앱 하나(Spotify, Apple Music, YouTube Music 등)로 음악을 틀어 둔 상태에서 확인합니다.
YouTube Music은 Premium이 아니면 앱을 벗어날 때 음악이 멈춥니다. 이는 YouTube Music의 정책이며 쉼표.와 관계없습니다.

**Expo Go로 확인할 수 있는 것 (무료)**

1. 「내 음악과 함께」를 고르고 숨 고르기를 시작 → 음악이 끊기거나 작아지지 않는지
2. 「소리 없음」으로 멍때리기를 시작하고 끝까지 둠 → 끝날 때도 음악이 그대로인지
3. 숨 고르기 중 음악 앱으로 가서 곡을 바꾸고 10초 뒤 돌아옴 → 남은 시간이 약 10초 줄어 있고 원의 움직임이 이어지는지
4. 숨 고르기 중 제어 센터를 내려 곡을 넘김 → 타이머가 멈추지 않는지
5. 「가벼운 비」로 시작 → 빗소리와 음악이 함께 들리는지(음악이 멈추지 않는지)

**개발 빌드에서만 확인할 수 있는 것 (Apple Developer Program 가입 후, 4단계에서 안내)**

6. 음악이 나오는 상태에서 「잔잔한 비」로 시작 → 빗소리가 나지 않고 「다른 앱 음악이 재생 중이라 빗소리는 꺼 두었어요.」가 보이는지
7. 빗소리만 나오는 중에 제어 센터에서 음악을 재생 → 빗소리가 천천히 사라지는지, 음악을 멈추면 다시 들어오는지
8. 무음 스위치를 켜고 「가벼운 비」로 시작 → 빗소리가 나지 않는지(음악 앱 소리는 그대로)

## 개발용 명령

```bash
npm run typecheck   # 타입 검사
npm test            # 호흡 리듬·알림 계획 계산 테스트
npx expo start      # 개발 서버 (w를 누르면 웹으로 열림)
npm run build:web   # 웹앱 배포 파일 만들기 (dist 폴더)
```

## 폴더 구조

```
src/app/          화면 (파일 하나가 화면 하나)
src/components/   버튼, 호흡 원, 소리 선택 등 화면 부품
src/lib/          호흡 리듬 계산, 타이머, 기기 저장, 알림 계획
public/           웹앱 HTML, 매니페스트, 서비스 워커, 아이콘
scripts/          웹 빌드 후처리(오프라인 파일 목록)
src/audio/        환경음 목록과 재생기
modules/other-audio/  다른 앱 음악 재생 여부를 알려 주는 iOS 모듈
assets/sounds/    환경음 파일과 출처 기록(CREDITS.md)
```
