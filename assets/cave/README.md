# 동굴 그림

- `cave-girl-nofire.webp` (웹에서 사용): `cave-girl.webp`에서 멈춘 불꽃만 지운 사본. 움직이는 불꽃은 코드(`src/components/cave/fireRenderer.ts`)가 그려 이중으로 보이지 않음
- `cave-girl.webp` (원본, iOS 앱에서 사용): 소유자가 고른 거대한 동굴 + 방석 위 여자아이 뒷모습 + 장작불(1672×941)
- `cave-ref-temp.webp` (예전 임시): 소유자가 보낸 동굴 레퍼런스(1344×768). 넓고 깊은 바위 동굴·빛 기둥·장작불은 기획과 같지만, 사람이 어른이고 방석이 없음. 해상도도 아이폰 세로 화면에는 낮음
- `cave-temp.webp`: 처음 쓰던 코드 생성 바위 질감(보관용, 지금은 쓰지 않음)

## 최종 동굴 그림 사양 (필수)
1. **장면:** 깊은 숲과 이어진 넓고 깊은 자연 동굴. 거대하고 거칠게 갈라진 바위 벽, 천장 틈으로 내려오는 옅은 푸른 빛(숲의 딥블루·청록과 이어짐), 바닥의 작은 돌들.
   낮고 폭신한 패브릭 방석(어두운 암벽·따뜻한 불빛에 어울리는 짙은 적갈색·올리브 계열) 위에 **무릎을 안고 앉아 불을 바라보는 작고 어린 여자아이의 뒷모습**(자연스러운 긴 머리나 단정한 중간 길이 머리, 얼굴 정면 불필요, 동굴 전체에 비해 작게). 아이가 바닥에 직접 앉은 듯 보이지 않게 방석이 분명히 보일 것, 아이 앞의 **장작더미와 낮은 불**. 불빛이 바위를 따뜻하게 비춤.
   숲 그림과 같은 사실적 시네마틱 화풍. 만화·게임 배경풍 금지.
2. **크기·비율:** 가로로 긴 파노라마 **4096×2796 이상**(세로 2796 = 아이폰 세로 화면 3배). 들어오면 왼쪽(깊은 동굴·빛 기둥)에서 오른쪽(아이·불)으로 카메라가 천천히 옮겨 감.
   세로 한 화면(가로 약 1290)에 아이·방석·불이 모두 들어가도록, 셋은 가로 폭 30% 안에 모아 주세요.
3. **불:** 그림의 불은 작고 낮게(또는 장작만). 일렁이는 불꽃·불빛은 코드로 얹습니다.
4. **파일:** WebP 또는 JPG(품질 85 이상), 1장. 가능하면 불 자리를 비운 판과 불 있는 판 2장.
5. **교체 위치:** `src/components/cave/caveConfig.ts`의 `CAVE_IMAGE`(파일·크기), `FIRE`(장작불 위치 비율), `CAVE_PAN`(시작·끝 가로 위치).

## 불 가까이 보기(불멍) — 실제 불꽃 영상 (선택, 받으면 교체)
- 지금은 코드로 그린 일러스트풍 장작불(임시). 사실적으로 하려면 **사람·손이 나오지 않는 장작불 근접 영상**(세로 1080×1920 이상, 10초 이상, 처음과 끝이 이어지는 반복 영상, mp4 H.264, 10MB 이하)
- 교체: `caveConfig.ts`의 `FIRE_VIDEO`에 파일을 넣으면 코드 불 대신 영상이 나오고, 장작 넣기·불티는 그 위에 그려짐
