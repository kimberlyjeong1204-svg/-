# 동굴 그림 (임시)

- `cave-temp.webp`: 기능 확인용 **임시 배경**(코드로 만든 바위 질감). 최종 자산이 아니며, 이 그림으로 동굴을 완료 처리하지 않습니다.
- 필요한 최종 자산
  1. 동굴 배경: 거대하고 거칠게 갈라진 실제 바위 암벽, 깊이감, 폭신한 방석에 무릎을 안고 기대 쉬는 작은 아이, 아이 앞 장작더미 자리. 숲 그림과 같은 사실적 시네마틱 화풍, 세로 9:16(1290×2796 이상). 불꽃은 코드로 얹으므로 그림에는 불꽃을 그리지 않거나 아주 약하게.
  2. 장작불 위치(그림 기준 비율 좌표)와 아이 위치: 교체 시 `src/components/cave/caveConfig.ts`의 `FIRE`만 바꾸면 불꽃·불빛 위치가 맞춰집니다.
  3. (선택) 장작불 소리: 지금은 Web Audio로 만든 타닥 소리. 라이선스 확인된 녹음을 받으면 교체.
