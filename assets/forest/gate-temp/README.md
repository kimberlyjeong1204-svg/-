# 숲 입구 임시 그림 (프리뷰 확인용)

- 프로젝트 소유자가 전달한 숲 입구 디자인 레퍼런스(「방해금지」 문)를 잘라 만든 **임시 층**입니다. 최종 에셋이 아닙니다.
- `gate-frame.webp`: 울타리·문기둥·주변 숲. 문 통로는 투명하게 잘라 뒤의 지금 숲 그림이 보이게 함. 색은 지금 숲 그림 쪽으로 약 55% 맞춤.
- `gate-door.webp`: 비스듬히 열린 문을 정면으로 펴고 통로 폭에 맞춰 늘린 문짝(배경 투명).
- 원본 좌표 기준: 941×1672. 문 통로 x 232~748, 문짝 자리 x 232~748 / y 640~1244.
- 최종 그림 층(울타리·문기둥, 닫힌 문짝, 앞 수풀)을 받으면 이 폴더를 교체합니다.
