# 쉼표 — 나무 풍경 개발 자산 v1

## 구성
- `assets/top_cap.png` 및 `.webp`: 상단 받침/매듭 (투명 배경)
- `assets/wood_01` ~ `wood_05` (`.png`, `.webp`): 개별 나무 조각 (투명 배경)
- `audio/wood_tap_01` ~ `wood_tap_10` (`.wav`, `.ogg`): **새로 합성한 원본 효과음** (44.1 kHz). 실제 나무 녹음이 아니며 최종 사운드 디자인 시 교체 가능
- `preview.png`: 개별 자산 검토용 이미지

## 구현 지시 (Claude에 전달)
1. 기존 `forest/stay`의 '풍경 흔들기' 체험에만 적용하고, 기존 숲 배경/음향 엔진을 보존한다.
2. 상단 받침은 고정하고 나무 조각 5개는 각각 독립적인 transform-origin(상단 끈 연결점)을 설정한다. Pointer Events 기반 드래그/터치, 감쇠 진자 애니메이션, 약한 바람의 자율 움직임을 구현한다.
3. 조각끼리 실제로 접촉할 때만 `wood_tap_01`~`10`을 무작위 재생한다. 강도에 따라 볼륨을 작게 조정하고 동시 재생 수를 제한한다. 기존 숲소리와 중복 엔진을 만들지 않는다.
4. Safari에서 첫 사용자 제스처 이후에만 소리를 재생한다. 무음/재생 실패 상태를 정직하게 표시한다.
5. `prefers-reduced-motion` 대응, 터치 타깃 44px 이상, 모바일 세로 화면 검증.
6. 이미지는 승인된 시안에서 수작업 마스크로 분리한 **v1 시제품**이다. 배경 제거 경계와 조각별 길이·끈 정렬을 실제 화면에서 점검하고 필요하면 보정할 것. 사진 기반 분리이므로 완벽한 픽셀 단위 투명화/원본 레이어 복원은 아니다.
7. main 병합 및 운영 배포 금지. 프리뷰에서 사용자 검토 후 진행.

## 저작권/품질
- 이미지는 이번 대화에서 새로 생성한 이미지에서 분리한 것.
- 효과음은 이 패키지 제작 중 직접 합성했으며 외부 녹음·샘플을 사용하지 않음.
- 최종 실물 나무 녹음과 같은 자연스러움은 보장하지 않음. 실기기에서 소리와 마스크 품질을 확인할 것.
