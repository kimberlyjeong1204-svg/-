# 쉼표 2.0 개발 계획

숲은 특정 기능의 배경이 아니라 앱의 중심 공간입니다.

```
홈(쉼표. / 나만의 숲) → 「숲으로 들어가기」 → (Phase 2: 울타리 · 「방해금지」 문 열기) → 나의 숲 → 숨 고르기 · 숲에 머물기 · 자연음 · 반복형 활동 → 다시 숲
```

원칙: 기존 노을 그라데이션 화면(코드 보관: `src/legacy/ZoneOutScreen.tsx`)과 숲 그림(작은 사람이 누워 있는 그림)은 삭제·교체하지 않습니다.
문구: 사용자에게 보이는 「멍때리기」는 모두 「숲에 머물기」. 슬로건은 쓰지 않고, 긴 감성 문구 대신 「숨 고르기」「비 켜기」「숲소리 켜기」「조용히 들어가기」처럼 짧게.
`main` 병합과 운영 배포는 프로젝트 소유자 승인 후에만 합니다.

## Phase 1 — 공통 숲 공간 (구현)

- `src/app/forest/_layout.tsx`가 숲 그림과 자연음을 한 번만 띄웁니다. 숲 안의 화면은 투명하게 겹쳐지므로 활동을 바꿔도 끊기지 않습니다.
- `/forest`: 아무것도 고르지 않아도 숲 전체 화면. 메뉴(뒤로, 소리 켜기, 환경음 설정, 활동)는 4초 뒤 사라지고 화면을 누르면 다시 보입니다.
- `/forest/breathe`: 숲 위 반투명 호흡 가이드. 끝나면 숲으로.
- `/forest/stay`: 숲에 머물기. 기본은 타이머 없음. 30초·1분·3분 선택, 쉬는 중 변경 가능. 끝나면 알람 없이 숲으로. 예전 `/zone-out` 주소도 여기로 연결.
- 홈: 「쉼표. / 나만의 숲 / 숲으로 들어가기」와 숲 안의 「숨 고르기 · 숲에 머물기」 바로 가기. 컵·책 장식은 뺌(울타리는 숲 입구에서).
- 소리: 처음 숲에 들어오면 한 번만 「숲의 소리를 들어볼까요?」(숲소리 켜고 들어가기 / 조용히 들어가기). 선택은 기기에 저장되어 다시 묻지 않고, 다음 방문 때 그대로 적용. 자동 재생 우회 없음, 무음 스위치 우회 없음.
- 소리 버튼은 실제로 재생이 확인될 때만 「켜짐」. 브라우저가 막으면 「숲소리가 멈춰 있어요. 눌러서 다시 켜기」.
- 숨 고르기 배경소리 「소리 없음」(Phase 2): 숲 환경음은 유지하고 숨 고르기 소리만 끔. 숲 전체 소리는 위쪽 공통 소리 버튼으로.
- 확장 준비: 날씨 상태(`clear` / `rain`, 기기 저장), 장면 목록(`forestScenes.ts`, 시간대 구분: twilight / night / dawn).

## Phase 2 — 숲 입구 · 숨 고르기 설정 변경 (진행 중)

- 숲 입구(`ForestGate`, PR #3 프리뷰에 **임시 그림**으로 연결): 소유자 레퍼런스를 잘라 만든 층(`assets/forest/gate-temp/`)을 씀. 최종 그림 층(울타리·문기둥, 닫힌 문짝, 앞 수풀)을 받으면 교체.
  - 처음 방문 때만 문 앞 → 소리 안내에서 고르면 문이 열림. 다시 방문하면 숲으로 바로. 설정 「숲 입구 다시 보기」.
  - 문짝 한 장을 원근 회전(살짝 걸렸다가 천천히 78°), 문틈 빛, 카메라가 문을 지나 들어감, 안개로 입구와 숲을 이음. 문 너머는 실제 숲 화면이라 같은 구도로 도착.
  - 숲소리는 문이 열리는 동안 5초에 걸쳐 다가오고, 문을 지나 숲에 머무는 동안 끊김 없이 이어짐(다시 시작하지 않음).
  - 경첩 소리는 문이 열릴 때 한 번만 재생하는 자리(`GATE_HINGE_SFX`)를 마련함. 라이선스 확인 후보를 들려드리고 승인 뒤 연결.
  - 웹 숲소리 재생기 교체(`bufferLoopPlayer.web.ts`): 아이폰 Safari에서 반복 이음새마다 오디오 요소를 새로 재생하다 막혀 끊기던 문제를 없앰. Web Audio 버퍼를 오디오 시계로 미리 예약해 이음새를 정확히 겹침.
  - 「바로 들어가기」로 건너뛰기, 동작 줄이기 설정이면 0.7초 페이드.
- 숨 고르기(구현, B1): 지름 140px 선 고리(안쪽 투명), 4초 뒤 조작 버튼·남은 시간만 숨고 고리·「들이쉬어요/내쉬어요」는 유지, 화면 누르면 다시.
- 숨 고르기 중 변경(구현): 「설정」 창에서 리듬(바로 새 들숨, 남은 시간 유지)·시간(새 시간으로 다시)·소리(2초 겹쳐 넘김, 비는 항상 하나). 창이 열린 동안 잠시 멈춤, 일시정지 중 변경 시 일시정지 유지. 예전 /breathe도 잠금 해제.
- 비 소리 채널: 재생기 두 개를 번갈아 써서 비 종류 전환 시 겹침 없이 넘김. Rain Mode(Phase 3)도 같은 채널 사용 예정.
- 「내 음악과 함께」: 빗소리 없음 + 숲소리 잠시 쉼(켜짐 선택은 유지, 버튼은 작은 꺼짐 아이콘).

## 숲 안에서 행동 발견하기 (구현)

- 첫 입장: 아래에 「숨 고르기 · 숲에 머물기 · 동굴 가기」를 작게(글자만) 보였다가 약 6.5초 뒤 숨김. 화면 터치나 작은 「···」로 다시. 상시 메뉴·게임풍 아이콘 없음
- 숨 고르기: 한 번의 터치로 바로 시작. 고리 선이 숨에 따라 밝아지고 굵어져 안내 문구 없이도 리듬이 보임
- 숲 만지기: 숲에 실제로 있는 것(잎·반딧불이)이 반응. 누른 자리의 잎이 번지듯 흔들리고 근처 반딧불이가 밝아지며 다가옴, 잎 스치는 소리
- 동굴은 숲 속 장소: 오른쪽 깊은 숲길 끝에 장작불 빛이 옅게 일렁이고, 누르면 그쪽으로 어둠이 번지며 동굴로. 나오면 어둠이 걷히며 숲

## 숲에 머물기 — 세 가지 체험 (구현, 풍경 그림은 임시)

- `/forest/stay`: 아래의 작은 선택지 「가만히 있기 · 숲소리 듣기 · 풍경 흔들기」. 고르지 않고 머물러도 되고, 언제든 전환. 숲소리는 숲 공간이 맡아 전환해도 다시 시작하지 않음. 버튼은 약 5초 뒤 숨고 터치하면 다시
- 가만히 있기: 숲의 움직임·자연음 그대로. 타이머·점수·완료 문구 없음(예전 선택 타이머는 화면에서 뺌, 코드 `useStayTimer.ts`는 보존)
- 숲소리 듣기: 화면을 은은하게 어둡게. 꺼져 있거나 Safari가 막았으면 「숲소리 켜기」를 눌러 시작(자동 재생 우회 없음). 터치하면 「숲소리 끄기 · 돌아가기」
- 풍경 흔들기: 나무 조각 5개가 진자로 움직임. 건드리거나 끌면 방향·세기만큼 흔들리고 감속, 이웃 조각이 부딪히면 세기에 맞는 나무 소리(Web Audio), 가만히 두면 바람에 아주 조금 흔들림(소리 없음)
- 필요한 최종 자산: 풍경 그림(받침 1장 + 조각 5장, 각각 배경 투명 PNG/WebP, 조각은 세로로 곧게 선 모습, 숲과 같은 사실적 딥블루·청록 조명), 나무 풍경 녹음(조각별 1~2개, 라이선스 확인). 교체 위치: `src/components/forest/WindChime.tsx`의 `Piece`, `src/audio/chimeSound.web.ts`

## 핵심 공간 — 동굴 (쉼표 2.0 필수 완료 범위, Rain Mode·부가 체험보다 우선)

숲이 조용히 머무는 곳이라면, 동굴은 마음이 복잡할 때 들어가 감정을 내려놓는 곳. 아무것도 하지 않아도 되고, 원하는 활동을 고를 수도 있음.

- **공간:** 깊은 숲과 이어진 독립된 동굴. 거대하고 거칠게 갈라진 실제 바위 암벽, 깊이감. 어둡지만 위협적이지 않고 아늑함. 폭신한 방석에 무릎을 안고 기대 쉬는 작은 아이, 그 앞의 장작불. 불빛이 바위를 은은하게 비춤. 타닥타닥 소리와 자연스러운 불꽃. 숲과 같은 사실적 시네마틱 화풍(만화·게임 배경풍 금지).
- **A. 내 마음 버리기:** 메모처럼 자유롭게 입력 → 종이로 표현 → 직접 불에 태우거나 찢어서 버림(타서 사라지거나 찢겨 흩어지는 애니메이션). 입력은 서버·기기 어디에도 저장·전송하지 않고, 활동을 마치거나 동굴을 나가면 완전히 지움. 기록 목록·감정 분석·점수·통계 없음.
- **B. 조약돌 던지기:** 바닥의 작은 조약돌을 골라 벽으로 던짐. 벽에 닿는 충돌음과 동굴 울림. 반복 가능, 점수·성공/실패 없음.
- **C. 가만히 머물기:** 아무것도 고르지 않아도 됨. 장작불 움직임과 소리만으로 충분하게. 버튼·문구 최소.
- **머무는 시간:** 입장 약 15분 뒤 한 번만 「나가기 / 더 머물기」. 더 머물기면 이후 안내 없음. 강제 종료·반복 알림·카운트다운·성취 문구 없음.
- **숲과 연결:** 숲에서 동굴로 자연스럽게 이동, 나가면 숲으로. 들어가면 숲소리는 천천히 작아지고 장작불 소리·동굴 공간감, 나오면 숲소리가 다시 커짐. 중복 재생·갑작스러운 끊김 없음.
- **필요 자산(최종):** 동굴 배경 그림(암벽·방석·무릎 안은 아이, 장작 자리 포함, 숲과 같은 화풍, 세로 9:16, 불꽃은 코드로 얹음), 장작불 소리(라이선스 확인). 받기 전에는 임시 화면으로 기능만 확인하며 **완료 처리하지 않음**.

## Phase 3 — Rain Mode (비 오는 숲)

- 별도 화면·타이머가 아니라 **공통 숲의 날씨 상태**. 숨 고르기·숲에 머물기 중에도 유지, 선택은 기기에 저장.
- 숲 메뉴에서 비 켜기/끄기.
- 소리: 앱에 있는 「가벼운 비」(Mixkit, 라이선스 확인됨)를 4~6초 페이드로 섞음. 비가 오면 귀뚜라미를 낮추고, 끄면 원래대로.
- 화면(원본 그림은 그대로, 위에 효과만): 깊이별 빗줄기, 잎과 바닥에 튀는 빗방울, 젖은 느낌(조금 어둡고 채도 낮게, 잎에 은은한 반짝임, 안개 조금 짙게), 반딧불이·별 줄임. 8초에 걸쳐 전환·복귀.
- 범위: 잔잔한 비 한 종류. 폭우·천둥·번개 제외.

## Phase 4 — 반복형 힐링 인터랙션 (하나씩, 소리·움직임 완성도 우선)

1. **나무 풍경 흔들기** (노을숲 우선): 풍경 흔들림, 맑은 울림과 잔향, 반복해도 소리가 부자연스럽게 겹치지 않게. 같은 화풍의 풍경 그림과 풍경 음원 필요.
2. **조약돌 쌓기**: 물리 표현 완성도를 시험한 뒤 개발 여부 결정.
3. **연못에 돌 던지기**: 연못이 있는 새벽숲의 핵심 활동(퐁당 소리, 동심원 물결).

추가 검토: 낙엽 모으기, 모래에 선 그리기, 모닥불에 장작 넣기, 민들레 홀씨, 반딧불이와 교감.
자연음 고도화: 드문 새·올빼미·잎 스침, 좌우 위치감, 갑작스러운 큰 소리 방지.

## Phase 5·6

- 재방문: 마지막 숲·날씨·음량·활동 기억, 바로 입장, 별똥별·옅은 안개 같은 드문 변화. 출석 보상·연속 기록 없음.
- 밤숲(반딧불이·별·올빼미·모닥불), 새벽숲(안개·이슬·연못·돌 던지기). 노을숲·밤숲은 시간대별로 그림과 데이터를 따로 둠.
