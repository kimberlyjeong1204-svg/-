# 쉼표 2.0 개발 계획

숲은 특정 기능의 배경이 아니라 앱의 중심 공간입니다.

```
홈(쉼표. / 나만의 숲) → 「숲으로 들어가기」 → (Phase 2: 울타리 · 「방해금지」 문 열기) → 나의 숲 → 숨 고르기 · 숲에 머물기 · 자연음 · 반복형 활동 → 다시 숲
```

원칙: 기존 노을 그라데이션 화면(코드 보관: `src/legacy/ZoneOutScreen.tsx`)과 숲 그림(작은 사람이 누워 있는 그림)은 삭제·교체하지 않습니다.
문구: 사용자에게 보이는 「멍때리기」는 모두 「숲에 머물기」. 슬로건은 쓰지 않고, 긴 감성 문구 대신 「숨 고르기」「비 켜기」「숲소리 켜기」「조용히 들어가기」처럼 짧게.
`main` 병합과 운영 배포는 프로젝트 소유자 승인 후에만 합니다.

## Phase 1 — 공통 숲 공간 (구현)

- `src/app/forest/_layout.tsx`가 숲 그림과 자연음을 한 번만 띄웁니다. 숲 안의 화면은 투명하게 겹쳐지므로 활동을 바꿔도 끊기지 않습니다.
- `/forest`: 아무것도 고르지 않아도 숲 전체 화면. 메뉴(뒤로, 소리 켜기, 환경음 설정, 활동)는 4초 뒤 사라지고 화면을 누르면 다시 보입니다.
- `/forest/breathe`: 숲 위 반투명 호흡 가이드. 끝나면 숲으로.
- `/forest/stay`: 숲에 머물기. 기본은 타이머 없음. 30초·1분·3분 선택, 쉬는 중 변경 가능. 끝나면 알람 없이 숲으로. 예전 `/zone-out` 주소도 여기로 연결.
- 홈: 「쉼표. / 나만의 숲 / 숲으로 들어가기」와 숲 안의 「숨 고르기 · 숲에 머물기」 바로 가기. 컵·책 장식은 뺌(울타리는 숲 입구에서).
- 소리: 처음 숲에 들어오면 한 번만 「숲의 소리를 들어볼까요?」(숲소리 켜고 들어가기 / 조용히 들어가기). 선택은 기기에 저장되어 다시 묻지 않고, 다음 방문 때 그대로 적용. 자동 재생 우회 없음, 무음 스위치 우회 없음.
- 소리 버튼은 실제로 재생이 확인될 때만 「켜짐」. 브라우저가 막으면 「숲소리가 멈춰 있어요. 눌러서 다시 켜기」.
- 숨 고르기 배경소리 「소리 없음」(Phase 2): 숲 환경음은 유지하고 숨 고르기 소리만 끔. 숲 전체 소리는 위쪽 공통 소리 버튼으로.
- 확장 준비: 날씨 상태(`clear` / `rain`, 기기 저장), 장면 목록(`forestScenes.ts`, 시간대 구분: twilight / night / dawn).

## Phase 2 — 숲 입구 · 숨 고르기 설정 변경 (진행 중)

- 숲 입구(`ForestGate`, PR #3 프리뷰에 **임시 그림**으로 연결): 소유자 레퍼런스를 잘라 만든 층(`assets/forest/gate-temp/`)을 씀. 최종 그림 층(울타리·문기둥, 닫힌 문짝, 앞 수풀)을 받으면 교체.
  - 처음 방문 때만 문 앞 → 소리 안내에서 고르면 문이 열림. 다시 방문하면 숲으로 바로. 설정 「숲 입구 다시 보기」.
  - 문짝 한 장을 원근 회전(살짝 걸렸다가 천천히 78°), 문틈 빛, 카메라가 문을 지나 들어감, 안개로 입구와 숲을 이음. 문 너머는 실제 숲 화면이라 같은 구도로 도착.
  - 숲소리는 문이 열리는 동안 5초에 걸쳐 다가옴. 경첩 소리는 라이선스 확인 후보를 들려드리고 승인 뒤 추가.
  - 「바로 들어가기」로 건너뛰기, 동작 줄이기 설정이면 0.7초 페이드.
- 숨 고르기 중 변경: 리듬(바로 새 주기, 전체 시간 유지), 시간(새 시간으로 다시), 배경소리(부드럽게 전환, 겹침 없음). 일시정지 중·연속 변경 가능.

## Phase 3 — Rain Mode (비 오는 숲)

- 별도 화면·타이머가 아니라 **공통 숲의 날씨 상태**. 숨 고르기·숲에 머물기 중에도 유지, 선택은 기기에 저장.
- 숲 메뉴에서 비 켜기/끄기.
- 소리: 앱에 있는 「가벼운 비」(Mixkit, 라이선스 확인됨)를 4~6초 페이드로 섞음. 비가 오면 귀뚜라미를 낮추고, 끄면 원래대로.
- 화면(원본 그림은 그대로, 위에 효과만): 깊이별 빗줄기, 잎과 바닥에 튀는 빗방울, 젖은 느낌(조금 어둡고 채도 낮게, 잎에 은은한 반짝임, 안개 조금 짙게), 반딧불이·별 줄임. 8초에 걸쳐 전환·복귀.
- 범위: 잔잔한 비 한 종류. 폭우·천둥·번개 제외.

## Phase 4 — 반복형 힐링 인터랙션 (하나씩, 소리·움직임 완성도 우선)

1. **나무 풍경 흔들기** (노을숲 우선): 풍경 흔들림, 맑은 울림과 잔향, 반복해도 소리가 부자연스럽게 겹치지 않게. 같은 화풍의 풍경 그림과 풍경 음원 필요.
2. **조약돌 쌓기**: 물리 표현 완성도를 시험한 뒤 개발 여부 결정.
3. **연못에 돌 던지기**: 연못이 있는 새벽숲의 핵심 활동(퐁당 소리, 동심원 물결).

추가 검토: 낙엽 모으기, 모래에 선 그리기, 모닥불에 장작 넣기, 민들레 홀씨, 반딧불이와 교감.
자연음 고도화: 드문 새·올빼미·잎 스침, 좌우 위치감, 갑작스러운 큰 소리 방지.

## Phase 5·6

- 재방문: 마지막 숲·날씨·음량·활동 기억, 바로 입장, 별똥별·옅은 안개 같은 드문 변화. 출석 보상·연속 기록 없음.
- 밤숲(반딧불이·별·올빼미·모닥불), 새벽숲(안개·이슬·연못·돌 던지기). 노을숲·밤숲은 시간대별로 그림과 데이터를 따로 둠.
